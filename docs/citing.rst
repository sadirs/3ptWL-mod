Citing and Acknowledgements
===========================

3PCF Modeling Framework
-----------------------

If 3ptWL-mod contributes to scientific results, cite the repository version
and the associated modeling work:

  Abraham Arvizu, Alejandro Aviles, Juan Carlos Hidalgo, Eladio Moreno,
  Gustavo Niz, Mario A. Rodriguez-Meza, Sofía Samario, and the LSST Dark
  Energy Science Collaboration, *Modeling the 3-point correlation function of
  projected scalar fields on the sphere*, JCAP **12** (2024) 049,
  `arXiv:2408.16847`_.

Neural-Network Acceleration
---------------------------

When the emulator workflow or its acceleration strategy is material to an
analysis, also cite:

  Sadi Ramirez, Miguel Icaza-Lizaola, Sebastien Fromenteau, Mariana
  Vargas-Magaña, and Alejandro Aviles, *Full shape cosmology analysis from BOSS
  in configuration space using neural network acceleration*, JCAP **2024**
  (08) 049 (2024), `doi:10.1088/1475-7516/2024/08/049`_.

Software Provenance
-------------------

Record the 3ptWL-mod commit, compiler, GSL and FFTW versions, Python version,
complete used-parameter file, input-table provenance, and emulator training
configuration in a reproducibility release.

Acknowledgements
----------------

3ptWL-mod uses or builds on FFTLog, BiHaloFit/Takahashi models, Zeno, Numerical
Recipes, GSL, and CLASS.  Alejandro Aviles acknowledges support by grants UNAM
PAPIIT IA101825 and SECIHTI CBF2023-2024-162.
